# Security Policy

## Supported Versions

Security fixes are prioritized for the latest released version of SILO.

## Reporting a Vulnerability

Please do not open a public GitHub issue for suspected vulnerabilities.

Use GitHub's private vulnerability reporting or a draft GitHub Security Advisory for this repository. If private reporting is unavailable, contact the maintainer through GitHub first and share only enough detail to establish a private channel.

Include:

- Affected SILO version or commit
- Operating system and Docker environment
- Steps to reproduce
- Impact and any known workarounds

The maintainers will acknowledge valid reports, investigate privately, and coordinate disclosure once a fix or mitigation is available.
