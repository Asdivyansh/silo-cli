# Contributing

Thanks for helping improve SILO.

## Development

```bash
npm install
npm run typecheck
npm test
npm run build
```

## Pull Requests

- Keep changes focused and include tests for behavior changes.
- Run `npm run typecheck`, `npm test`, and `npm run build` before opening a PR.
- For security-sensitive changes, describe the threat model impact in the PR body.

## Security

Please do not open a public issue for suspected vulnerabilities. Follow [SECURITY.md](SECURITY.md) so maintainers can investigate privately first.
